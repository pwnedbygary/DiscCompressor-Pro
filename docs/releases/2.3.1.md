DiscCompressor Pro 2.3.1 can update itself: the installed Windows app and the AppImage tell you when a new release is out, then download and install it when you ask. The AppImage also works with AppImageUpdate and GearLever, and the window now fits an 800×600 screen.

## Download

| System            | File                                       | Notes                                                           |
| ----------------- | ------------------------------------------ | --------------------------------------------------------------- |
| Windows 10/11 x64 | `DiscCompressorPro-2.3.1-Setup-x64.exe`    | Installs for the current user; you can change the folder.       |
| Windows 10/11 x64 | `DiscCompressorPro-2.3.1-Portable-x64.exe` | Runs without installing.                                        |
| Linux x86-64      | `DiscCompressorPro-2.3.1-x86_64.AppImage`  | Make it executable (`chmod +x`) and run it. No libfuse2 needed. |

- The Windows files aren't code-signed, so SmartScreen may warn the first time: choose **More info → Run anyway**.
- If the AppImage can't be mounted (no FUSE at all, as in some containers), start it with `--appimage-extract-and-run`.
- `SHA256SUMS.txt` lists the checksums of every file. `DiscCompressorPro-2.3.1-sources.tar` holds the source code of the GPL and LGPL parts of the bundled tools, the AppImage runtime and the Windows installer, plus the MAME and maxcso sources and Electron's FFmpeg.
- `latest.yml`, `latest-linux.yml` and `DiscCompressorPro-2.3.1-x86_64.AppImage.zsync` are read by the updaters; you don't need to download them.
- chdman 0.289 and maxcso 1.13.0 are included, as in 2.2.2.

## What's new since 2.2.2

### Updates

- **The app looks for a new release** when it starts and once a day, and the status bar says when there is one. In the installed Windows app and the AppImage, **Help → About** downloads it and restarts into the new version; a downloaded update is also installed when you quit. Nothing is downloaded until you click **Download update**, and the app won't restart while jobs are running.
- The AppImage downloads only the parts of the new version that changed. The Windows installer is downloaded whole, over 100 MB.
- The portable EXE, and an AppImage in a folder you can't write to, can't replace themselves, so they link to the release page instead.
- The check asks GitHub for the latest release and sends no identifier for your copy. To turn it off, use **Settings → Updates**; **Check now** in **Help → About** still works.
- **AppImageUpdate and GearLever.** The AppImage now carries update information, and each release has the AppImage's `.zsync` file, so AppImageUpdate downloads only what changed and GearLever finds new versions.
- When the app updates an AppImage whose file name includes the version, the new file gets the new version's name and the old one is removed, so update any launcher that points to it. To keep one name across updates, rename the AppImage without the version, e.g. `DiscCompressorPro.AppImage`.

### Small screens

- **The window fits an 800×600 screen.** Its minimum size is now 800×540 instead of 940×600.
- When the queue is narrower than 512 pixels, as in an 800-pixel window with the job settings open, its rows hide the drag handle and the time left to make room for the file names, and the toolbar shows the job counts as coloured dots with numbers (hover for the label) and hides the space saved. Counts that don't fit are left out whole, least important first, rather than cut off.
- **The console starts closed** the first time you open the app; if you had it open in an earlier version, it stays open. While it's closed, a dot on its button tells you about new warnings (amber) or errors (red). Info jobs open it, since that's where their result is.
- Stopping the queue and cancelling a job are logged as information instead of warnings, so they don't light the dot.

## Upgrading from 2.2

- 2.2.2 and earlier have no updater, so download 2.3.1 by hand this once: replace the AppImage or the portable EXE, or run the new installer. Your settings carry over. From then on, the installed app and the AppImage update themselves, and the portable EXE tells you when a new version is out.
- Coming from 2.1 or 1.x? Read the [2.2.2 release notes](https://github.com/pwnedbygary/DiscCompressor-Pro/releases/tag/v2.2.2) too: ISOs of CD-based discs now become CD CHDs by default.
- Version 2.3.0 was never released; its changes are part of 2.3.1.
