DiscCompressor Pro 2 is a ground-up rewrite. It still converts BIN/CUE, GDI, ISO, CHD, CSO and ZSO images (and now DAX too), but everything around that is new: a redesigned interface, a safer job engine, real progress for every job, Windows builds, and chdman and maxcso included, so there is nothing else to install.

## Download

| System            | File                                       | Notes                                                        |
| ----------------- | ------------------------------------------ | ------------------------------------------------------------ |
| Windows 10/11 x64 | `DiscCompressorPro-2.1.2-Setup-x64.exe`    | Installs for the current user; you can change the folder.    |
| Windows 10/11 x64 | `DiscCompressorPro-2.1.2-Portable-x64.exe` | Runs without installing.                                     |
| Linux x86-64      | `DiscCompressorPro-2.1.2-x86_64.AppImage`  | Make it executable (`chmod +x`) and run it. No libfuse2 needed. |

- The Windows files aren't code-signed, so SmartScreen may warn the first time: choose **More info → Run anyway**.
- If the AppImage can't be mounted (no FUSE at all, as in some containers), start it with `--appimage-extract-and-run`.
- `SHA256SUMS.txt` lists the checksums of every file. `DiscCompressorPro-2.1.2-sources.tar` holds the source code of the GPL and LGPL parts of the bundled tools, the AppImage runtime and the Windows installer, plus the MAME and maxcso sources and Electron's FFmpeg.

## What's new since 1.3.1

### Nothing else to install, on Windows too

- chdman 0.289 (from MAME) and maxcso 1.13.0 are included. 1.x needed them installed separately.
- Windows is supported, with an installer and a portable EXE next to the Linux AppImage. 1.3.1 was Linux-only.
- You can still use your own copies of the tools: choose them in **Settings → Tools**. The status bar shows which versions were found.

### A new interface

- **A queue you can drive with the mouse or the keyboard.** Drop files or whole folders: images inside are found automatically, and track files that a cue or GDI sheet refers to aren't added twice. Reorder by dragging or with Alt+↑/↓, select with Shift/Ctrl or by dragging a rectangle, and duplicate, remove or run jobs again. It stays fast with hundreds of jobs.
- **Every job shows what it will produce**, its progress and the time left while it runs, and the space it saved when it's done. The bar above the queue adds up the space saved.
- **A job settings panel** for one job or many at once. Options that can't work are disabled, with the reason shown: for example, why a disc with audio tracks can't become an ISO. **Apply to all** copies a job's settings to the whole queue, and **Save as default** uses them for new jobs.
- **A console** with search, All/Warnings/Errors filters, copy and save.
- **13 themes**, plus one that follows your system's light or dark mode. All of 1.x's themes are still there.
- **Keyboard shortcuts** for the common actions (listed under **Help → Keyboard shortcuts**; F1 opens Help), and screen reader support for the queue and the theme menu.
- A notification when the queue finishes while the window is in the background, progress on the taskbar, and the computer stays awake while jobs run. Minimize to tray is still available.

### Conversions

| From            | To                                                                  |
| --------------- | ------------------------------------------------------------------- |
| BIN/CUE         | CHD; CSO / CSO v2 / ZSO for single-data-track discs                 |
| GDI             | CHD (GD-ROM)                                                        |
| ISO             | CHD (as CD or DVD), CSO, CSO v2, ZSO                                |
| CHD             | BIN/CUE, GDI or ISO (extract), recompressed CHD, CSO / CSO v2 / ZSO |
| CSO / ZSO / DAX | ISO (extract), CHD, or another CSO format                           |
| CHD             | Info and Verify                                                     |

- **CHD:** up to four codecs, only hunk sizes that chdman accepts, and CD or DVD media for ISOs. Extracting gives BIN/CUE, GDI or ISO; a CD becomes an ISO only if it has a single data track.
- **CSO, CSO v2 and ZSO** with maxcso, with a choice of block size and compression methods. DAX images can now be read too.
- **Info and Verify** for CHD files. Verify only passes when chdman confirms every checksum.
- **Real progress for both tools.** chdman's own progress is shown; maxcso prints none when another program runs it, so its progress is measured from the data it reads (or, when extracting, writes).
- `.m3u` playlists for multi-disc games, output next to the source files or into one folder, up to four jobs at the same time, and a thread count per job.
- Save and load the queue. Queue files from 1.x load too.

### Safer by design

- Each job works in a temporary `.dcp-…` folder inside the output folder (hidden on Linux), and finished files are moved into place only when the job succeeds, so a cancelled or failed job leaves nothing half-written. Anything a crash leaves behind is removed at the next start.
- An input file is never overwritten, and jobs never overwrite each other's results.
- **Existing outputs are skipped by default.** 1.x replaced them. To write a numbered copy of a skipped job, press Ctrl+R (Run again) and start the queue, or change **When the output already exists** in Settings to keep both or replace. Choosing **Replace it** asks for confirmation first.
- **Move originals to the trash after success** sends them to the trash rather than deleting them, and never applies to Info or Verify. Turning it on asks for confirmation first.

### Fixed

- With **Delete Originals on Success** turned on, 1.x also deleted the input of successful Info and Verify jobs, so checking a CHD could permanently delete it. 2.x never touches the input of Info or Verify, and moves originals to the trash instead of deleting them.
- Converting a GDI image to CHD failed with 1.x's default settings: 1.x asked chdman for 2,048-byte hunks, which chdman rejects for CDs.

### Under the hood

- Rewritten from scratch in TypeScript on Electron 44, React 19 and Tailwind 4, with 166 unit tests, plus end-to-end tests that run the real chdman and maxcso on Windows and Linux.
- The app's window is sandboxed with a strict content security policy, and only the app's own page can talk to the rest of the app. On Linux distributions that restrict user namespaces, such as Ubuntu 24.04, the AppImage starts without Chromium's sandbox.
- Releases are now built by GitHub Actions from their tag, with checksums. The Linux tools are built from the source code of their release tags, and their builds are reproducible.

## Upgrading from 1.x

- Your settings carry over: the output folder, default format, theme, playlists, minimize to tray and custom tool paths. **Delete Originals on Success** becomes **Move originals to the trash after success**: if you had it on, it stays on, and originals now go to the trash instead of being deleted.
- If you chose your own chdman or maxcso in 1.x, 2.x keeps using them instead of the bundled ones; click **Find automatically** under each in **Settings → Tools** to switch. If 1.x used the copies on your PATH, 2.x now uses its bundled copies instead; choose yours in **Settings → Tools** to keep them.
- New CSO, CSO v2 and ZSO jobs use maxcso's standard compression (**Balanced**) instead of 1.x's **Fast**, so they take longer and give slightly smaller files. For 1.x's speed, choose **Fast** under **Compression effort** in the job settings and click **Save as default**.
- Existing outputs are now skipped instead of replaced; see "Safer by design" above.
